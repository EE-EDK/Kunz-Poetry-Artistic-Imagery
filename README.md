# Shadowshining

Selected poems, 2009–2025 — spoken, scored, pictured, and cut locally.

GitHub: [EE-EDK/Kunz-Poetry-Artistic-Imagery](https://github.com/EE-EDK/Kunz-Poetry-Artistic-Imagery)
(`main`). Independent repo under `ai-video-photo/`; MASTER does not track it.

This is the poem-film track under `ai-video-photo/`. It is lighter than
[The Void is Crimson](../The%20Void%20is%20Crimson/): twenty-five independent
pieces instead of one 540-shot act. Each poem keeps its own voice, music, SFX,
stills, timing, and video. Shared tooling lives at the project root.

Public showing (kunzhub):
https://kunz-ai-hub.tailb1d0b7.ts.net/p/shadowshining-selected-poems/

When a cut is finished, publish it there: the poem's top image (if it has
one) becomes a playable poster; click fullscreens; ended returns to that
20-poem page. Procedure: `GROK.md` → Hub publish.

Work locally. ElevenLabs, Epidemic Sound, and Grok image/video runs all land
as files you drop in `inbox/` or straight into a poem folder. The web consoles
are backup, not the pipeline.

**Pull from Downloads.** Saying "move image", "pull image", "retrieve", or
the same idea for video/audio means: look in `C:\Users\edk7c\Downloads` for
what just landed (last few minutes), rename it, catalog it, and file it into
the matching `poems/NN-slug/` slot. If the poem or slot is not obvious, the
agent should say so and wait rather than guess.

## Layout

| Path | What |
|------|------|
| `paths.py` | Root-relative paths. Move the folder; nothing else needs editing. |
| `src/catalog.json` | The 25-poem index plus per-folder status flags. Regenerated by bootstrap. |
| `texts/shadowshining-selected-poems.md` | Canonical collection text. |
| `poems/NN-slug/` | One folder per poem — the unit of work. |
| `poems/NN-slug/poem.md` | Title + body. |
| `poems/NN-slug/transcript.txt` | Plain text sent to forced alignment. |
| `poems/NN-slug/audio/elevenlabs/` | Spoken TTS / cloned-voice takes. |
| `poems/NN-slug/audio/music/` | Beds, scores, stems. |
| `poems/NN-slug/audio/sfx/` | Spot effects you made or generated. |
| `poems/NN-slug/audio/epidemic/` | Epidemic Sound (or other library) pulls. |
| `poems/NN-slug/audio/mix/` | Full mixed wav. |
| `poems/NN-slug/timing/` | Forced-alignment JSON, spoken-word JSON, SRT. |
| `poems/NN-slug/images/` | Stills generated from the poem. |
| `poems/NN-slug/video/` | Lyric cuts and assembled film. |
| `inbox/` | Drop new artifacts here, then file them by poem. |
| `scripts/align_timings.py` | ElevenLabs forced alignment → timing/. |
| `scripts/burn_lyrics.py` | ffmpeg: SRT onto video or a black lyric card. |
| `scripts/bootstrap.py` | Rebuild the 25-folder tree and refile known dumps. |

## Pipeline (per poem)

1. **Text** — `poem.md` / `transcript.txt` already exist for all 25.
2. **Voice** — drop an ElevenLabs wav/mp3 into `audio/elevenlabs/`.
3. **Timing** — `python scripts/align_timings.py 01` writes character/word
   timestamps and an SRT. That SRT is what on-screen text follows.
4. **Score / SFX** — music beds in `audio/music/`, library pulls in
   `audio/epidemic/`, one-off spots in `audio/sfx/`. Mix lands in `audio/mix/`.
5. **Images** — generate stills from the poem locally (Grok CLI, SuperGrok
   login, `$0`) into `images/`.
6. **Video** — `python scripts/burn_lyrics.py 01` burns the SRT onto an
   existing mp4, or onto a black frame + voice if there is no picture yet.

Do not mix two poems in one folder. If a cue is reused, copy it.
