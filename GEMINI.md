# GEMINI.md — Shadowshining

Governance for this project. Same-tier precedence: `GROK.md` → `AGENTS.md` →
`CLAUDE.md`. This file adds mandates that apply when they do not conflict.

- Canonical poem text: `texts/shadowshining-selected-poems.md`. Do not rewrite.
- Timestamps: ElevenLabs forced alignment only. No hand-waved cadence.
- Secrets: `.env` is local. Never copy the API key into docs, commits, or chat.
- Media stays per-poem. Shared tools at repo root. No Void-is-Crimson imports.
- Images and image→video: local Grok CLI, SuperGrok login, `XAI_API_KEY` unset.
- Validate file existence before claiming a pipeline step is done.
- "Move / pull / retrieve / grab" media: search Downloads (last few minutes),
  rename, catalog, file by poem. If unsure, ask — do not guess the poem.
  Procedure: `GROK.md` → Downloads pull.
- A finished `*FINAL*.mp4` is not live until published onto kunzhub
  (`GROK.md` → Hub publish). The showing is twenty-five poems, one film
  each; do not rebuild the 91-page collection to add one cut.
